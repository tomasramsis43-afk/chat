# سالم — شات ويب موبايل

شات موقع: أي حد يعمل حساب، يشوف قائمة الأعضاء، ويبعت رسائل خاصة real-time.

## التشغيل محليًا

```bash
npm install
node server.js
```

هيشتغل على `http://localhost:3000`. افتحه من المتصفح على الموبايل هيكون متصمم مخصوص لمقاس الشاشة (mobile-first).

## النشر (Deploy) — مثلاً على Render

1. ارفع المجلد ده على GitHub repo جديد منفصل عن FTC2.
2. على Render: New → Web Service → اختار الريبو.
3. Build command: `npm install`
4. Start command: `node server.js`
5. أضف Environment Variable: `JWT_SECRET` بقيمة عشوائية طويلة (مهم للأمان في الإنتاج).

> ملاحظة: قاعدة البيانات هنا SQLite (ملف `chat.db` محلي) — بسيطة وكافية للبداية. لو المشروع كبر واحتاج بيانات تفضل موجودة بعد كل deploy على Render (لأن الملفات بتتمسح)، ابعتلي وأنقل المشروع لـ PostgreSQL/Neon زي FTC2.

## البنية

```
chat-app/
├── server.js        # Express + Socket.io + كل الـ API
├── db.js            # إعداد SQLite
├── public/
│   ├── index.html   # واجهة الدخول + قائمة الأعضاء + الشات
│   ├── style.css     # تصميم مظلم متجاوب للموبايل
│   └── app.js        # منطق العميل + الاتصال بالسوكيت
└── chat.db           # قاعدة البيانات (بتتعمل تلقائي أول تشغيل)
```

## المميزات الحالية
- تسجيل / دخول بكلمة مرور مشفرة (bcrypt) + JWT
- قائمة أعضاء مع حالة "متصل / غير متصل" لحظيًا
- محادثات خاصة 1-إلى-1 بالـ real-time (Socket.io)
- مؤشر "بيكتب..."
- سجل الرسائل محفوظ ورجعت لما تفتح المحادثة تاني
- تصميم مخصص للموبايل بالكامل (RTL عربي)

## أفكار للتوسعة لاحقًا
- صور شخصية حقيقية بدل الحرف الأول
- إشعارات push
- غرف جماعية مش بس محادثات فردية
- رفع صور/ملفات في الشات
